# English Dictionary Web App
<h3>A simple and interactive English Dictionary web app built using HTML, CSS, and JavaScript that fetches real-time word meanings, pronunciations, and examples using a free dictionary API.</h3>

This project is a web-based English Dictionary application that allows users to search for any word and instantly get its meaning, pronunciation, and example usage. Built using HTML, CSS, and JavaScript, it integrates the Free Dictionary API through Axios to fetch and display word data dynamically. The app features a clean, responsive interface and includes an audio pronunciation button for better learning. It’s a beginner-friendly yet practical project showcasing API integration, DOM manipulation, and user interaction using pure JavaScript.
